## 🛠️ V5.0 分件式獨立按鍵蓋終極升級重點

1. **100% 鎖定保留 V4.0 已實測完美之機身結構**
   - **零晃動貼身內腔**：維持 $158.55 \times 75.92 \times 7.75\text{ mm}$（四角 $R = 8.29\text{ mm}$），四邊與四角 100% 緊密貼合機身不晃動。
   - **順暢好拆頂部擋板**：維持左右長邊內縮 $0.55\text{ mm}$、上下短邊與四角內縮 $0.45\text{ mm}$，穩固防脫且大拇指一推即可輕鬆拆下。
   - **精準鏡頭與充電開孔**：後置三鏡頭、閃光燈、頂部雙麥克風與底部充電喇叭開孔 100% 維持不變。

2. **全新「側壁內階梯挖空 + 3 顆防脫落獨立浮動按鍵蓋 (Drop-In Floating Button Caps)」分件設計**
   - **手機殼側壁「內寬外窄」階梯槽**：在手機殼右側壁切出 3 組內寬外窄的階梯式貫穿窗（內側階梯止擋面位於 $X = 39.20\text{ mm}$，外側保留 $0.51\text{ mm}$ 擋牆，頂部帶微拱自支撐設計免支撐好印）。
   - **3 顆獨立圓潤鵝卵石按鍵蓋（音量+、音量-、電源鍵）**：每顆按鍵蓋底部皆帶有 **$0.48\text{ mm}$ 防掉出內法蘭擋邊**（比外窗寬 $1.40\sim 1.80\text{ mm}$、高 $1.50\text{ mm}$），頂部為溫潤不割手的鵝卵石圓弧頂面。
   - **簡易安裝不脫落**：安裝手機前，先將 3 顆按鍵蓋從手機殼**內側**放入對應的階梯槽中，接著將手機推入殼內即可自動將按鍵蓋鎖定於槽內，**既不會往外掉出、也不會往內掉落**！

3. **零塑膠彈性阻力 + $+0.15\text{ mm}$ 自由浮動防誤壓間隙（絕不誤壓重啟、還原裸機清脆手感）**
   - **精準距離控制（絕不誤壓）**：裸機按鍵頂面位於 $X = 38.57\text{ mm}$，手機殼內側階梯止擋面位於 $X = 39.20\text{ mm}$（總間距 $0.63\text{ mm}$）；獨立按鍵蓋之內法蘭厚度設定為 **$0.48\text{ mm}$**（內底面位於 $X = 38.72\text{ mm}$），在未按壓時具備 **$+0.15\text{ mm}$ 自由浮動安全間隙**，安裝後 **100% 不會預壓手機按鍵導致重啟**！
   - **零阻力清脆按壓**：因為按鍵蓋為完全獨立的浮動分件，按壓時無須克服任何塑膠薄片的彎曲阻力，手指輕觸即可直接傳遞清脆的裸機按鍵段落感！
