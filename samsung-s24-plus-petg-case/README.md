## 🛠️ V3.3 實機測試回饋四大升級重點

1. **100% 實心純平內壁與底板（移除內壁兩側卸力凹槽與內底紋理）**
   - 原本內壁兩側的縱向凹槽是為了輔助側壁外張而設的「彈性卸力槽」，但實測發現會削弱側壁夾持力。現已將內壁與內底改為 **100% 實心純平結構**，大幅強化側壁包覆剛性。

2. **依據 S24+ 原廠級 STEP CAD (`gs24_plus.step`) 100% 精準校正開孔與按鍵座標**
   - **後置三鏡頭視窗**：中心 $X$ 軸校正至 **$+25.15\text{ mm}$**（距機身側緣 $12.82\text{ mm}$）；三顆鏡頭中心 $Y$ 軸校正至真機 CAD 座標 **$+66.74\text{ mm}$ / $+49.57\text{ mm}$ / $+32.41\text{ mm}$**（開孔直徑 $16.54\text{ mm}$，完美貼合真機 $\varnothing 14.61\text{ mm}$ 鏡頭環）。
   - **LED 閃光燈孔**：中心精準校正至 **$X = +11.75\text{ mm}, Y = +58.16\text{ mm}$**（孔徑 $7.10\text{ mm}$）。
   - **機身四角與頂底開孔**：裸機四角半徑校正為 **$R = 8.33\text{ mm}$**；頂部雙麥克風孔校正至 **$X = +13.4\text{ mm}$**（靠近鏡頭側），底部喇叭孔校正至 **$X = -16.2\text{ mm}$**。

3. **解決安裝過鬆問題：收緊內腔公差 + 360° 全周向 $1.10\text{ mm}$ 強效防脫前唇**
   - **收緊內腔尺寸**：內腔寬度收緊至 **$76.16\text{ mm}$**（半寬 $38.08\text{ mm}$，單邊僅 $0.11\text{ mm}$ 緊配裕度）、內腔長度 **$158.90\text{ mm}$**、垂直深度收緊至 **$7.92\text{ mm}$**。
   - **360° 全周向深咬合防脫卡扣**：將正面防脫卡扣內縮量大幅提升至 **左右長邊內縮 $1.10\text{ mm}$**（卡扣內緣達 $X = \pm 36.98\text{ mm}$，實質覆蓋裸機邊框達 **$0.99\text{ mm}$**）、**上下短邊與四角內縮 $0.95\text{ mm}$**，手機推入後四邊與四角皆被牢牢鎖定，絕不掉出！

4. **V3.3 全新「全高微彎 $0.20\text{ mm}$ 極薄 S 型弧線連體按鍵」— 兼顧一體式極簡美觀與極致輕柔手感**
   - **一體式極簡無破洞外觀**：取消舊版左右兩側醜陋的大方孔，恢復**全高（$4.50\text{ mm}$）流線連體外觀**，外部僅在按鍵上下各留一條乾淨的 **$0.85\text{ mm}$ 水平分離細縫**，外緣帶圓潤倒角絕不割手。
   - **下修壁厚至 $0.20\text{ mm}$**：將按鍵彈性壁厚度設定為 **$0.20\text{ mm}$** 極薄微彎簧片，並將中央觸發頂針改為窄型橢圓頂針（$Y$ 軸寬僅 $1.35\sim 1.65\text{ mm}$），讓 $>85\%$ 的跨度皆為純粹 $0.20\text{ mm}$ 極薄彈性變形區！（*切片提示：若使用 $0.4\text{ mm}$ 噴嘴切片，請於切片軟體開啟「偵測薄壁 Detect thin walls」或將 Arachne「最小牆寬 Minimum wall width」調降至 $45\%\sim 50\%$（$0.18\sim 0.20\text{ mm}$），以確保切片軟體完整生成此 $0.20\text{ mm}$ 薄壁路徑*）。
   - **餘弦微彎 S 型外拱曲線 + 內側純垂直柱面掏空**：在 $X$-$Y$ 平面採用平滑的餘弦微彎外拱曲線 $x(u) = A \cdot \frac{1 + \cos(\pi u)}{2}$（兩端與側壁平滑相切、中央向外微彎拱起 $0.72\text{ mm}$），且按鍵內壁保持**純垂直柱面**，單指輕觸即清脆回彈！
