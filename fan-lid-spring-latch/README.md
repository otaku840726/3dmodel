# 風扇快拆蓋子 - 雙側彈片防脫落改良版 (Snap-Fit Fan Lid with Compliant Spring Tabs)

本專案為針對 3D 列印風扇轉接座蓋子（原檔：`蓋子9.stl`）進行的結構優化改良。解決原始設計在長時間運轉震動與環境發熱下容易塑性潛變（Creep）、疲勞鬆動脫落的問題。

歷經多次迭代與回饋驗證，最新版（**v2 精密修正版**）徹底解決了先前版本「彈片區域過大太鬆」以及「卡筍凸出過度無法順暢卡入」的痛點，實現清脆卡合、剛韌兼備、徒手秒拆的高可靠機構。

## 迭代優化與工程問題解決 (Changelog & Engineering Fixes)

### 1. 解決「彈片區域過大、手感太鬆」問題
- **痛點剖析**：先前版本切槽向底板內部切削深達 13.6mm（至 $X = \pm 35.0\text{ mm}$），由於底板厚度僅 1.0mm，過長的懸臂臂長造成抗彎剛度大幅折損（梁撓度與長度呈三次立方關係 $\delta \propto L^3$），按壓時底板整體軟塌。
- **v2 精密修正**：
  - 將底板切槽向內深度**由 13.6mm 大幅縮減至 3.6mm**（切槽止於 $X = \pm 45.0\text{ mm}$）。
  - 保留內側寬達 **15.0mm 的完整剛性底板框架**。
  - 彈片寬度由 16.0mm 優化為精準舒適的 **12.0mm**。
  - 剛度提升超過 **30 倍**，徹底杜絕鬆垮，按壓回彈堅挺乾脆，壽命倍增。

### 2. 解決「卡筍部分太突出、厚度不足卡入」問題
- **痛點剖析**：原版蓋子內側卡扣突入達 1.50mm（頂點位於 $X = 47.10\text{ mm}$）。然而風扇底座（Comp 0）的下倒角深度實測僅有 1.0mm（$X = 47.50 \sim 48.50\text{ mm}$）。先前的 1.5mm 卡扣突出過深，超過底座倒角容納厚度，容易在安裝時直接頂死在底座本體上，導致卡不進去或嚴重卡滯。
- **v2 精密修正**：
  - 先進演算法完整切除舊有過厚突起，重建高精度微凸卡齒。
  - **內凸厚度精準調校為 0.55mm**（卡齒頂點 $X = 48.05\text{ mm}$，底座外壁為 $X = 48.50\text{ mm}$）。
  - **有效咬合深度為 0.45mm**，完美落入底座 1.0mm 倒角凹槽中，並保有 0.55mm 的防呆間隙，絕不頂死。
  - **22° 順暢導引斜坡**（$Z = 1.70 \sim 3.20\text{ mm}$）：蓋上時滑順自導入，輕壓即「喀噠」鎖定。
  - **40° 鎖定斜角**（$Z = 1.00 \sim 1.50\text{ mm}$）：防止軸向震動脫落，拉拔鎖定力道紮實。

### 3. 保留加高按壓指引與應力消除
- **加高 2.5mm 拇指按鍵（按壓版）**：頂部邊緣倒角，按壓觸感柔和省力。
- **切槽末端 R0.5mm 圓角（Fillet）**：徹底消除切槽死角的應力集中，防止層間疲勞微裂紋。

## 尺寸規格 (Specifications)

- **蓋子外廓尺寸 (Lid)**：$100.2 \times 100.2 \times 19.0\text{ mm}$ (加高按鈕版) / $16.5\text{ mm}$ (齊平版)
- **底座外廓尺寸 (Base)**：$97.0 \times 97.0 \times 6.5\text{ mm}$ (含 4 根風扇孔位定位柱，柱高 2.5mm)
- **中央排風通孔 (Lid Opening)**：$60.0 \times 58.0\text{ mm}$
- **彈片寬度 (Tab Width)**：$12.0\text{ mm}$
- **切槽間隙 (Slot Width)**：$1.0\text{ mm}$ (匹配標準 0.4mm 噴頭)
- **卡扣內凸量 (Catch Protrusion)**：$0.55\text{ mm}$ (咬合深度 $0.45\text{ mm}$)
- **底板切槽長度 (Floor Cut)**：僅 $3.6\text{ mm}$ (保留 $15.0\text{ mm}$ 堅固底框)

## 3D 列印建議 (Print Settings)

- **擺盤方向**：底面朝下（$Z = 0$ 貼平熱床），開口朝上。
- **支撐設定**：**全件 100% 免支撐（Support-Free）**。所有切槽皆垂直熱床，卡扣斜角均在自支撐範圍內。
- **建議線材**：**PETG** 或 **ABS / ASA**（優選，抗疲勞韌性與耐熱性最佳；PLA 亦可順暢使用）。
- **壁厚外圈 (Perimeters/Walls)**：建議 3～4 圈（確保彈片本體為實心列印）。
- **填充率**：25% ~ 40% (建議 Gyroid 陀螺狀填充)。
- **層高**：0.20 mm。
